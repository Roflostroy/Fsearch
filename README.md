# 🔍 Bash File Finder

Интерактивный bash-скрипт для поиска файлов в Linux прямо из терминала.
Простое меню, ASCII-арт и три способа поиска — по имени, расширению или дате изменения.

---

## 📋 Возможности

- Поиск файлов **по имени**
- Поиск файлов **по расширению**
- Поиск файлов **по времени изменения** (за последние N дней)
- Поиск файлов **по правам доступа**
- Поиск файлов **по размеру**
- Интерактивное меню с ASCII-баннером
- Чистый вывод — ошибки доступа не засоряют результат
- Добавлен просмотр каталогов
